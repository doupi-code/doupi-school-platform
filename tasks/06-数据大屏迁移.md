## 关键技术点

### 1. SSE 实时数据 (`useScreenSSE.ts`)
```typescript
import { useEffect, useState } from 'react';

export const useScreenSSE = (url: string) => {
  const [data, setData] = useState<any>(null);

  useEffect(() => {
    const eventSource = new EventSource(url);
    eventSource.onmessage = (event) => {
      setData(JSON.parse(event.data));
    };
    eventSource.onerror = () => {
      eventSource.close();
      // 5秒后重连
      setTimeout(() => { /* 重新创建 EventSource */ }, 5000);
    };
    return () => eventSource.close();
  }, [url]);

  return data;
};
```

### 2. 自适应缩放（在 ScreenLayout.tsx 中已实现）
- 设计基准 1920×1080
- 通过 CSS `transform: scale()` 等比缩放
- 使用 `ResizeObserver` 监听窗口变化

### 3. ECharts 主题
- 深色背景: `#0f1923`
- 图表配色: 使用品牌蓝 `#3088F4` 系列渐变
- 所有图表使用 `echarts-for-react` 封装

### 4. 数字翻牌器
- 使用 `react-countup` 或自定义 CSS 动画
- 数字变化时有滚动动效
