# 任务：后端安全加固

## 优先级：P0（最高，必须最先完成）

## 背景
当前后端存在严重安全漏洞，必须在前端开发开始前修复。

## 任务清单

### 1. 微信网关鉴权改造

**文件**: `doupi-server/doupi-framework/src/main/java/com/doupi/framework/config/SecurityConfig.java`

**当前问题**: `/api/wx/**` 被设为 `permitAll()`，所有小程序 API 无需认证即可访问。

**改造步骤**:
1. 在 `SecurityConfig` 中，将 `/api/wx/**` 从 `permitAll()` 移除
2. 仅保留 `/api/wx/auth/login` 和 `/api/wx/auth/register` 为公开接口
3. 创建新文件 `doupi-framework/src/main/java/com/doupi/framework/security/filter/WxJwtAuthFilter.java`
4. 该 Filter 继承 `OncePerRequestFilter`，逻辑：
   - 检查请求路径是否匹配 `/api/wx/**`（排除 login/register）
   - 从 `Authorization` Header 提取 Token
   - 调用现有的 `TokenService.getLoginUser(request)` 验证
   - 验证通过设置 `SecurityContextHolder`
   - 验证失败返回 401
5. 在 SecurityConfig 中注册此 Filter（在 `JwtAuthenticationTokenFilter` 之前）

**参考现有代码**:
- `doupi-framework/src/main/java/com/doupi/framework/security/filter/JwtAuthenticationTokenFilter.java`
- `doupi-framework/src/main/java/com/doupi/framework/web/service/TokenService.java`

### 2. 微信登录接口改造

**文件**: `doupi-recruit/src/main/java/com/doupi/recruit/controller/DoupiWxDispatcherController.java`

**当前问题**: 登录时通过手机尾号硬编码判定角色，且生成假 Token `"wx_tk_" + System.currentTimeMillis()`。

**改造步骤**:
1. 找到 `case "auth.login"` 分支
2. 移除所有手机尾号硬编码的角色判定逻辑
3. 改为：
   - 通过 `wx.login()` 的 code 调用微信接口换取 openid
   - 查询 `sys_user` 表（或新建 `wx_user` 表）匹配 openid 获取用户角色
   - 调用 `TokenService` 生成真实 JWT Token
   - 返回 Token 和用户信息
4. 确保小程序端收到的 Token 格式与 Web 端一致

### 3. 微信网关重构（策略模式）

**文件**: `doupi-recruit/src/main/java/com/doupi/recruit/controller/DoupiWxDispatcherController.java`

**当前问题**: 500+ 行的 switch-case 上帝类。

**改造步骤**:
1. 创建接口 `com.doupi.recruit.handler.WxActionHandler`
2. 为每个 action 创建独立 Handler（放在 `handler/` 包下）：
   - `AuthLoginHandler` — auth.login
   - `AppointmentCreateHandler` — appointment.create
   - `AppointmentListHandler` — appointment.list
   - `AppointmentQueryByPhoneHandler` — appointment.queryByPhone
   - `DashboardStatsHandler` — dashboard.stats
   - `ConfigSummaryHandler` — config.summary
   - （其他所有 action 逐个拆分）
3. 创建 `WxActionHandlerRegistry` 使用 `@Autowired List<WxActionHandler>` 自动注册
4. 重构 Dispatcher 为 3 行代码：获取 action → 查找 handler → 执行
