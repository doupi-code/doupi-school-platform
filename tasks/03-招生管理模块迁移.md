- **功能**: 核心 KPI 卡片 + 趋势图表
- **界面结构**:

  ```
  ┌─────────┬─────────┬─────────┬─────────┐
  │ 今日预约 │ 今日核销 │ 累计预约 │ 转化率   │

  └─────────────────────┴───────────────────┘
  ```
- **关键点**:
  - 使用 Ant Design `Statistic` + `Card` 组件制作 KPI 卡片
  - 卡片带渐变色背景（参考旧代码的 CSS 渐变）
  - 图表使用 `echarts-for-react`
  - 数字动画使用 `react-countup`（可选）
- **参考**: `back/.../views/recruit/dashboard/index.vue`

### 2. 预约管理 (`pages/recruit/appointment/index.tsx`)
- **后端接口**: `/recruit/appointment/list`, CRUD, `/recruit/appointment/verify`
- **功能**: 预约列表 + 搜索筛选 + 新增预约 + 编辑 + 核销操作
- **关键点**:
  - 列表需要状态标签（待核销/已核销/已取消），用不同颜色 Tag
  - 核销操作：点击后弹确认框，调用核销接口
  - 搜索条件：日期范围、状态、校区、关键词
  - 导出功能
- **参考**: `back/.../views/recruit/appointment/index.vue`

### 3. 核销管理 (`pages/recruit/verify/index.tsx`)
- **后端接口**: `/recruit/appointment/verify`
- **功能**: 专用核销页面，输入核销码/扫码枪 → 核销
- **关键点**:
  - 大字体输入框，支持扫码枪自动提交
  - 核销成功/失败的全屏反馈（绿色✓ / 红色✗）
  - 核销成功后显示预约详情卡片
  - 输入框自动聚焦
- **参考**: `back/.../views/recruit/verify/index.vue`

### 4. 教师绑定 (`pages/recruit/binding/index.tsx`)
- **后端接口**: `/recruit/teacherBinding/list`, CRUD
- **功能**: 绑定教师微信 + 分配招生码
- **关键点**: 标准 CRUD + 二维码展示

### 5. 校区管理 (`pages/recruit/campus/index.tsx`)
- **后端接口**: `/recruit/campus/list`, CRUD
- **功能**: 管理多个校区信息
- **关键点**: 标准 CRUD，包含地址、联系方式、图片上传

### 6. 排班配置 (`pages/recruit/config/index.tsx`)
- **后端接口**: `/recruit/config/list`, CRUD
- **功能**: 配置可预约的日期和时间段
- **关键点**:
