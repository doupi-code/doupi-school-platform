# 任务：库存管理模块迁移（Web 管理端）

## 优先级：P1

## 参考代码位置
- 旧 Vue 页面: `back/doupi-full-backup-20260930/doupi-web-admin/src/views/stock/`
- 旧 API 文件: `back/doupi-full-backup-20260930/doupi-web-admin/src/api/stock/`

## 需要迁移的页面

### 1. 物品管理 (`pages/stock/goods/index.tsx`)
- **后端接口**: `/stock/goods/list`, CRUD
- **功能**: 耗材（纸张、墨盒等）基础信息管理
- **关键点**: 标准 CRUD + 分类筛选 + 库存数量展示
- **难度**: 🟢 低

### 2. 供应商管理 (`pages/stock/supplier/index.tsx`)
- **后端接口**: `/stock/supplier/list`, CRUD
- **功能**: 供应商信息管理
- **难度**: 🟢 低

### 3. 入库单 (`pages/stock/in/index.tsx`)
- **后端接口**: `/stock/in/list`, CRUD
- **功能**: 入库单管理（主子表结构）
- **关键点**:
  - 使用 **Drawer（抽屉）** 替代弹窗，给明细表格更多空间
  - 入库单 = 主表（日期、供应商、经办人） + 明细表（物品、数量、单价）
  - 明细表使用可编辑表格（`EditableProTable`）
  - 保存时自动更新物品库存
- **难度**: 🟡 中

### 4. 出库单 (`pages/stock/out/index.tsx`)
- **后端接口**: `/stock/out/list`, CRUD, `/stock/out/void`
- **功能**: 出库单管理（主子表结构）
- **关键点**:
  - 结构与入库单类似（Drawer + 可编辑明细表）
  - 出库关联到文印记录（从文印登记自动生成出库单）
  - 支持**作废**操作（作废后回滚库存）
  - 库存不足时阻止出库
- **难度**: 🟡 中

### 5. 入库明细 (`pages/stock/inItem/index.tsx`)
- **后端接口**: `/stock/inItem/list`
- **功能**: 跨入库单的明细汇总查询
- **难度**: 🟢 低

### 6. 出库明细 (`pages/stock/outItem/index.tsx`)
- **后端接口**: `/stock/outItem/list`
- **功能**: 跨出库单的明细汇总查询
- **难度**: 🟢 低

### 7. 盘点管理 (`pages/stock/check/index.tsx`)
- **后端接口**: `/stock/check/list`, CRUD
- **功能**: 库存盘点记录
- **关键点**:
  - 创建盘点单 → 填入实际数量 → 系统计算盈亏
  - 盈亏 = 实际数量 - 系统库存
- **难度**: 🟡 中

### 8. 明细报表 (`pages/stock/report/detail.tsx`)
- **后端接口**: `/stock/report/detail`
- **功能**: 出入库明细台账
- **关键点**: 筛选条件 + 数据表格 + 导出 Excel
- **难度**: 🟢 低

### 9. 月度台账 (`pages/stock/report/monthly.tsx`)
- **后端接口**: `/stock/report/monthly`
- **功能**: 按月汇总的库存变动报表
- **关键点**: 月份选择 + 汇总表格 + ECharts 柱状图
- **难度**: 🟡 中

## 验收标准
- [ ] 入库/出库的主子表 Drawer 交互流畅
- [ ] 出库时库存不足给出提示
- [ ] 作废出库单后库存正确回滚
- [ ] 盘点盈亏计算正确
- [ ] 报表数据与实际出入库记录一致
