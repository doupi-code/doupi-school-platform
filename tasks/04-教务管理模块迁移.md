### 3. ⭐ 文印登记 (`pages/edu/record/index.tsx`) — 最复杂页面
- **后端接口**: `/edu/printRecord/list`, `/edu/printRecord/ocr`, CRUD
- **功能**: OCR 识别微信截图 → 自动提取打印信息 → 登记文印记录
- **难度**: 🔴 高（原 Vue 代码 2000+ 行）

**改造为 3 步骤表单**:

```
步骤 1: 上传/粘贴              步骤 2: 确认识别结果           步骤 3: 提交登记
┌────────────────────┐     ┌────────────────────┐      ┌────────────────────┐
│                    │     │ 教师: 张老师 ✓     │      │ ✅ 登记成功！      │
│  拖拽文件到此处     │     │ 科目: 数学   ✓     │      │                    │
│  或粘贴截图 Ctrl+V │     │ 份数: 50     ✓     │      │ 文印编号: PR2026001│
│  或点击选择文件     │     │ 单双面: 双面  ✓    │      │ 扣减纸张: 50张     │
│                    │     │ 纸张: A4     ✓     │      │                    │
│  [支持: jpg/png]   │     │                    │      │ [继续登记] [返回]  │
└────────────────────┘     │ [上一步] [确认提交]│      └────────────────────┘
                           └────────────────────┘
```

**关键子组件**:
1. **FileDropUpload 组件** — 必须迁移
   - 拖拽上传区域（`onDragOver`, `onDrop`）
   - 粘贴上传（`document.addEventListener('paste')`，读取 `clipboardData.files`）
   - 点击选择上传
   - 上传到 `/common/upload` 接口
   - 参考: `back/.../components/FileDropPasteUpload/index.vue`
   
2. **OCR 结果编辑表单** — 新建
   - 显示 OCR 识别出的字段（教师、科目、份数等）
   - 每个字段可手动修改
   - 教师下拉选择（从教师管理接口获取列表）

3. **Steps 步骤条** — 使用 Ant Design `Steps` 组件
