# 任务：系统管理模块迁移（Web 管理端）

## 优先级：P0（基础模块，其他模块依赖）

## 背景
系统管理模块是 RuoYi 框架的核心模块，包含用户、角色、菜单、部门等基础管理功能。全部是标准 CRUD 页面，使用 Ant Design ProTable 可以快速迁移。

## 参考代码位置
- 旧 Vue 页面: `back/doupi-full-backup-20260930/doupi-web-admin/src/views/system/`
- 旧 API 文件: `back/doupi-full-backup-20260930/doupi-web-admin/src/api/system/`
- 后端接口不变，直接复用

## 需要迁移的页面

### 1. 用户管理 (`pages/system/user/index.tsx`)
- **后端接口**: `/system/user/list`, `/system/user/{id}`, CRUD
- **功能**: 用户列表 + 左侧部门树筛选 + 新增/编辑弹窗 + 重置密码 + 分配角色
- **关键点**: 
  - 左侧使用 `Tree` 组件展示部门树
  - 新增表单中的部门选择用 `TreeSelect`
  - 角色分配使用 `Transfer` 穿梭框或多选
- **参考**: `back/.../views/system/user/index.vue`

### 2. 角色管理 (`pages/system/role/index.tsx`)
- **后端接口**: `/system/role/list`, CRUD
- **功能**: 角色列表 + 新增/编辑（含菜单权限树）+ 分配用户 + 数据权限
- **关键点**: 
  - 编辑弹窗中用 `Tree` 组件展示菜单权限树（可勾选）
  - 数据权限设置（全部/自定义/本部门/本部门及以下）

### 3. 菜单管理 (`pages/system/menu/index.tsx`)
- **后端接口**: `/system/menu/list`, CRUD
- **功能**: 树形表格展示菜单层级 + 新增/编辑弹窗
- **关键点**: 
  - 使用 ProTable 的 `expandable` 展示树形数据
  - 菜单类型：目录(M)、菜单(C)、按钮(F)
  - 图标选择器组件

### 4. 部门管理 (`pages/system/dept/index.tsx`)
- **后端接口**: `/system/dept/list`, CRUD
- **功能**: 树形表格展示部门层级
- **关键点**: 类似菜单管理的树形表格

### 5. 岗位管理 (`pages/system/post/index.tsx`)
- **后端接口**: `/system/post/list`, CRUD
- **功能**: 标准 CRUD 表格
- **参考模板**: 最简单的标准 ProTable 页面

### 6. 字典管理 (`pages/system/dict/index.tsx` + `data.tsx`)
- **后端接口**: `/system/dict/type/list`, `/system/dict/data/list`
- **功能**: 字典类型列表 → 点击进入字典数据列表（两级页面）
- **关键点**: 列表中的类型名称可点击，跳转到对应的字典数据页面

### 7. 参数设置 (`pages/system/config/index.tsx`)
- **后端接口**: `/system/config/list`, CRUD
- **功能**: 标准 CRUD 表格

### 8. 通知公告 (`pages/system/notice/index.tsx`)
- **后端接口**: `/system/notice/list`, CRUD
- **功能**: 公告列表 + 富文本编辑器
- **关键点**: 
  - 编辑弹窗中需要富文本编辑器（推荐使用 `@uiw/react-md-editor` 或 `TinyMCE`）

## 通用 CRUD 页面开发模板

每个标准 CRUD 页面遵循以下模式：

```typescript
import { PageContainer } from '@ant-design/pro-components';
import { ProTable } from '@ant-design/pro-components';
import type { ProColumns, ActionType } from '@ant-design/pro-components';
import { Button, Modal, Form, message } from 'antd';
import { PlusOutlined, DeleteOutlined, EditOutlined } from '@ant-design/icons';
import { useRef, useState } from 'react';
import Authorized from '@/components/Authorized';

const XxxPage: React.FC = () => {
  const actionRef = useRef<ActionType>();
  const [modalOpen, setModalOpen] = useState(false);
  const [form] = Form.useForm();
  const [editingId, setEditingId] = useState<number | null>(null);

  const columns: ProColumns[] = [
    { title: 'ID', dataIndex: 'xxxId', hideInSearch: true },
    { title: '名称', dataIndex: 'xxxName' },
    { title: '状态', dataIndex: 'status', valueEnum: { '0': '正常', '1': '停用' } },
    { title: '创建时间', dataIndex: 'createTime', valueType: 'dateTime', hideInSearch: true },
    {
      title: '操作', valueType: 'option',
      render: (_, record) => [
        <Authorized key="edit" permission="xxx:xxx:edit">
          <a onClick={() => handleEdit(record)}>编辑</a>
        </Authorized>,
        <Authorized key="delete" permission="xxx:xxx:remove">
          <a onClick={() => handleDelete(record.xxxId)}>删除</a>
        </Authorized>,
      ],
    },
  ];

  // handleAdd, handleEdit, handleDelete, handleSubmit...

  return (
    <PageContainer>
      <ProTable
        actionRef={actionRef}
        columns={columns}
        request={async (params) => {
          const res = await listXxx({ ...params, pageNum: params.current, pageSize: params.pageSize });
          return { data: res.rows, total: res.total, success: true };
        }}
        rowKey="xxxId"
        toolBarRender={() => [
          <Authorized permission="xxx:xxx:add">
            <Button type="primary" icon={<PlusOutlined />} onClick={handleAdd}>新增</Button>
          </Authorized>,
        ]}
      />
      <Modal title={editingId ? '编辑' : '新增'} open={modalOpen} onOk={handleSubmit} onCancel={() => setModalOpen(false)}>
        <Form form={form} layout="vertical">
          {/* 表单字段 */}
        </Form>
      </Modal>
    </PageContainer>
  );
};
```
