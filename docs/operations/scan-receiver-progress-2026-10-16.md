- 新安装 vsftpd 3.0.5-0ubuntu3.1，apt 同时新安装 ssl-cert；没有升级业务应用。
- 专用账号 ricoh_printroom，无 SSH 登录 shell（/usr/sbin/nologin）。

## 4. 验证经过与证据

### 4.1 服务器本机权限验证

专用用户登录、上传无敏感内容 txt 成功；匿名登录、覆盖、下载和删除被拒绝。

此结果只证明服务器服务与权限配置可以工作，不能代替打印机实扫。

### 4.2 当前电脑通过公网被动 FTP 上传

同一专用账号进入 incoming，上传 37 字节测试 txt，返回：

```text
226 Transfer complete.
```

标准日志记录公网来源 113.57.10.164，并以完整传输标记 c 结束。

此结果证明该电脑的公网被动 FTP 链路可用，不能证明理光使用相同的数据连接方式。

### 4.3 理光首次实扫与等待状态

设备扫描文件状态中，多次测试出现“请稍候”或取消。服务端未收到 PDF。
设备“错误描述”页面列出连接错误、验证错误、权限错误、发送错误的通用解释，不是本次任务的精确错误码。

曾提出“扫描日志打印受阻”的假设，因为扫描日志设置为“打印并全部删除”，且碳粉报空。没有证据证明日志已满或本次任务正在等待日志打印，因此该假设不能作为根因，也没有据此清日志或重启设备。

短时放宽来源后捕获到扫描时段新连接，来源仍为 113.57.10.164。不同公网出口的假设没有得到支持，临时广域规则随后收回。

### 4.4 命令日志定位到主动 FTP

在仅允许被动模式的配置下，设备真实交互为：

```text
USER ricoh_printroom
230 Login successful.
CWD incoming
250 Directory successfully changed.
TYPE I
200 Switching to Binary mode.
PORT 10,10,125,187,255,210
550 Permission denied.
```

设备还发送 RETR 检查文件，服务器按禁止下载策略返回 550。不能把这个 RETR 结果等同于上传失败的唯一原因。

明确结论：账号密码、目录可用；设备实际使用主动 FTP，初始 port_enable=NO 明确拒绝 PORT。

### 4.5 启用主动模式后的单轮实测

用户明确授权修改并扫描后，得到：

```text
230 Login successful.
250 Directory successfully changed.
PORT 10,10,125,187,255,207
500 Illegal PORT command.
PORT 10,10,125,187,255,206
500 Illegal PORT command.
```

控制连接公网来源是 113.57.10.164，PORT 声明的却是 10.10.125.187；保留的对端地址校验拒绝两者不一致。

本轮没有成功 STOR、完整 PDF 或页数验证结果。
没有关闭 port_promiscuous 校验，没有放开任意目标回连，也没有修改学校网络。

## 5. 能确定和不能确定的结论

已确定：

1. 服务器可搭建接收服务，普通电脑可以通过公网被动 FTP 上传。
2. 理光能连到服务器、认证成功、进入接收目录。
3. 本次设备实际使用主动 FTP，并声明内网数据连接地址。
4. 初始阻塞为主动模式被禁；启用后的阻塞为 PORT 地址校验。
5. 打印机实扫直传没有成功，不具备开始后续应用上线的链路验收条件。

不能据此宣称：

- 该型号绝对不支持被动模式。网页配置未找到对应选项，官方型号资料中未查到明确切换方法，仍可向厂商进一步确认。
- 只关闭地址校验就能修复。关闭校验不会自动建立公网到学校内网的路由。
- 所有公网 FTP 直传都不可行。这里受限于当前设备模式和现场网络，换网络或建立 VPN 后需重新实测。
- 碳粉告警、日志满或系统维修提示就是本次失败原因。现有证据不足。

执行经验：不能因型号支持 FTP 就默认支持公网可用的被动模式；应先取得真实 FTP 命令，再确定服务器配置和网络要求，避免让用户反复扫描后才定位协议差异。

## 7. 将来恢复开发时保留的业务方案

链路验收应先于应用开发：至少三次真实多页扫描完整到达，校验格式与页数，测试重复文件、中断和恢复。

后续扫描收件箱需要：

- 成功传输事件驱动入箱，不能仅以文件大小短期不变判断完成；持久化事件游标并处理日志轮换、重启与重复事件。
- 私有归档、附件 ID、服务端哈希、PDF 格式校验、大小限制与异常记录；接收区不能进入 Nginx 公开目录。
- 列表、鉴权预览、待登记/已登记/忽略/异常状态；选择或解析文件不扣库存。
- 复用登记表，带入原稿页数，教师、份数与印刷单双面人工确认；扫描单双面不能直接视为印刷要求。
- 保存登记、关联扫描件、扣库存须在同一事务中完成；支持请求幂等、并发锁、试卷答案拆分整体回滚，重印须显式操作。
- 原先发现历史 /profile/ 文印附件可匿名访问。该问题未修复，若重启项目需要单独完成私有上传、业务鉴权下载、历史引用迁移、旧静态地址/通用下载/哈希秒传绕过保护。
- 历史迁移先盘点与备份，再复制校验、切换引用、关闭旧公开副本；保留头像等公共资源。
- 测试环境演练后再生产部署，保护服务器已有未提交修改，并提供空间监控和回滚清单。
