# 项目索引地图 — 汉外华襄学校综合平台

> 本文档是项目的一站式导航索引，帮助快速定位各端代码、模块、页面与开发进度。维护时间：2026-10-07。

---

## 一、整体架构总览

Monorepo 单仓聚合，前后端分离，纯原生部署（无 Docker），生产/测试物理隔离。

```
doupi-school-platform/
├── doupi-server/            # 后端 Spring Boot 4 + JDK 17（10 个 Maven 模块）
├── doupi-web-admin-react/   # 管理后台 React 19 + TS + Ant Design 6
├── doupi-web-client-react/  # 门户官网 React 19 + Tailwind CSS
├── doupi-app/               # 移动端 App（uni-app x + UTS，三端原生）
├── doupi-miniApp/           # 微信原生小程序（招生预约）
├── deploy/                  # 原生部署（systemd/nginx/sudoers）
├── scripts/                 # 运维脚本 + SQL 增量脚本
├── docs/                    # 技术文档（01~08）
└── .github/workflows/       # 3 条 CI/CD 流水线
```

## 三、后端模块索引（doupi-server）

| 模块 | 职责 | 关键 Controller |
|---|---|---|
| doupi-admin | 启动入口 + 全部 Web 控制器（37 个） | 见下方分组 |
| doupi-framework | 安全框架/Redis/Druid 连接池 | — |
| doupi-system | RBAC 权限体系 | SysUser/SysRole/SysDept/SysMenu/SysDict/SysPost/SysNotice/SysConfig/SysLogin/SysProfile |
| doupi-edu | 教务业务（实体 14） | EduClass/EduTeacher/EduMaterial/EduPrintRecord/EduGoodsKit/EduCelebration |
| doupi-stock | 物资进销存（实体 11） | StockGoods/StockIn/StockOut/StockCheck/StockSupplier/StockReport |
| doupi-recruit | 招生（实体 5，8 Controller） | RecruitAppointment/RecruitBinding/RecruitCampus/RecruitConfig/RecruitDashboard/WxDispatcher/SchoolCms/SchoolPublic |
| doupi-cms | 官网 CMS（实体 9，3 Controller） | CmsPublic/CmsPortal/CmsPageBuilder |
| doupi-quartz | 定时任务 | SysJob/SysJobLog |
| doupi-generator | 代码生成 | GenController |
| doupi-common | 通用基类/异常/常量 | BaseController |

**Controller 清单路径**：`doupi-server/doupi-admin/src/main/java/com/doupi/web/controller/`（按 common/edu/monitor/screen/stock/system/tool 分组）
