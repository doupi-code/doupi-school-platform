## 三、后端安全加固方案

### 3.1 微信网关鉴权改造

```java
// 新增 WxAuthFilter（在 SecurityConfig 中注册）
// 1. 小程序登录时，通过 wx.login() 获取 code
// 2. 后端用 code 换取 openid + session_key
// 3. 生成真实 JWT Token（payload 含 openid + role）
// 4. 后续请求携带此 Token，WxAuthFilter 验证

@Component
public class WxJwtAuthFilter extends OncePerRequestFilter {
    @Override
    protected void doFilterInternal(request, response, chain) {
        String token = request.getHeader("Authorization");
        if (token != null && token.startsWith("Bearer wx_")) {
            // 验证 JWT 签名 + 过期时间
            // 解析出 openid + role
            // 设置 SecurityContext
        }
        chain.doFilter(request, response);
    }
}
```

### 3.2 微信网关重构（策略模式）

```java
// 定义 Action 处理器接口
public interface WxActionHandler {
    String getAction();  // 如 "appointment.create"
    Object handle(Map<String, Object> payload, String openid);
}

// 每个业务一个 Handler 实现
@Component
public class AppointmentCreateHandler implements WxActionHandler {
    @Override
    public String getAction() { return "appointment.create"; }
    @Override
    public Object handle(Map<String, Object> payload, String openid) {
        // 业务逻辑
    }
}

// 网关自动发现并路由
@RestController
public class WxDispatcherController {
    @Autowired
    private Map<String, WxActionHandler> handlers; // Spring 自动注入

    @PostMapping("/api/wx/dispatcher")
    public AjaxResult dispatch(@RequestBody Map<String, Object> body) {
        String action = (String) body.get("action");
        WxActionHandler handler = handlers.get(action);
        if (handler == null) return AjaxResult.error("未知操作");
        return AjaxResult.success(handler.handle(body.get("payload"), getCurrentOpenid()));
    }
}
```
