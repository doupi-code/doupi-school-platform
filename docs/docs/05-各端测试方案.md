> **文档版本**: v2.0

## 一、测试策略总览

### 1.1 测试金字塔

```
           /  E2E 测试  \           ← 少量关键业务流程
          / 集成测试(API) \         ← 覆盖所有后端接口
         / 组件/页面测试    \       ← 覆盖关键交互组件

```

## 三、前端测试方案

### 3.1 Web 管理端测试

#### 3.1.1 组件级测试（Vitest + React Testing Library）

```typescript
// 示例：字典标签组件测试
describe('DictTag', () => {
  it('应根据字典值渲染对应标签', () => {
    render(<DictTag value="1" dictType="sys_normal_status" />);
    expect(screen.getByText('正常')).toBeInTheDocument();
  });

  it('未找到字典值时应显示原始值', () => {
    render(<DictTag value="unknown" dictType="sys_normal_status" />);
    expect(screen.getByText('unknown')).toBeInTheDocument();
  });
});
```

#### 3.1.2 E2E 测试（Playwright）

| 场景 | 步骤 | 验证点 |
|:--|:--|:--|
| **登录流程** | 输入账号密码 → 点击登录 → 进入首页 | 页面跳转、用户名展示、菜单加载 |
| **预约列表** | 登录 → 进入招生管理 → 搜索预约 | 列表渲染、分页、筛选条件生效 |
| **文印登记** | 粘贴截图 → OCR 识别 → 确认提交 | 预填信息准确、提交成功反馈 |
| **出库操作** | 新建出库单 → 选择物品 → 填数量 → 提交 | 库存扣减、单号生成 |
| **数据大屏** | 进入大屏 → 全屏模式 → 点击钻取 | 图表渲染、数据更新、弹窗交互 |

## 五、性能测试方案

### 5.1 后端压测（4 核 4G 服务器基准）

| 测试场景 | 并发用户数 | 目标 QPS | 目标响应时间 |
|:--|:--|:--|:--|
| 预约列表查询 | 50 | ≥ 200 | P95 < 500ms |
| 预约创建 | 20 | ≥ 50 | P95 < 1000ms |
| 文印 OCR 识别 | 2 | ≥ 2 | P95 < 15s |
| 数据大屏 SSE 推送 | 10 | — | 连接稳定 > 30min |
| 出库操作 | 10 | ≥ 30 | P95 < 800ms |

### 5.2 前端性能指标

| 指标 | Web 管理端 | Web 用户端 | 小程序 |
|:--|:--|:--|:--|
| FCP (首次内容绘制) | < 1.5s | < 1.0s | < 1.5s |
| LCP (最大内容绘制) | < 2.5s | < 2.0s | < 2.5s |
| TTI (可交互时间) | < 3.0s | < 2.5s | < 3.0s |
| JS Bundle 大小 | < 500KB (gzip) | < 200KB (gzip) | < 2MB (首包) |

### 5.3 压测工具

```bash
# 使用 Apache JMeter 或 k6 进行后端压测
# 示例 k6 脚本
k6 run --vus 50 --duration 60s script.js
```

## 六、安全测试清单

| 测试项 | 验证内容 | 优先级 |
|:--|:--|:--|
| 微信网关鉴权 | 无 Token / 伪造 Token / 过期 Token 全部拦截 | P0 |
| 越权访问 | 家长角色不能调用管理接口 | P0 |
| SQL 注入 | MyBatis 参数化查询验证（`#{}` 而非 `${}` ） | P0 |
| XSS 防护 | 预约备注等输入字段的 HTML 转义 | P1 |
| CSRF 防护 | POST/PUT/DELETE 接口的 Token 校验 | P1 |
| 文件上传 | 文件类型白名单、大小限制、文件名清理 | P1 |
| Druid 控制台 | 生产环境不可外网访问 | P0 |
| 敏感信息 | 日志中不输出手机号全文、Token 密钥 | P1 |
