# 网站备案配置实施计划

**目标：** 将两端页脚的公安备案审核中状态替换为鄂公网安备42011102006651号，并允许管理员维护备案信息。

**方案：** 扩展现有 `doupi_cms_global` 的 `footer` JSON，复用 `cms:config:list/edit` 权限、保存接口和缓存失效逻辑。在现有页脚编辑表单增加 ICP 链接、公安备案号、公安备案链接，保留现有 ICP 备案号。两端使用同一份已保存配置，缺失新字段时兼容本次核准值；使用附件图标。链接仅允许 HTTP/HTTPS。

**技术：** React、TypeScript、Ant Design、现有 Spring CMS 接口、MySQL JSON。
