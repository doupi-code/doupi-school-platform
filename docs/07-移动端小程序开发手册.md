# 07 - 移动端小程序开发手册

## 1. 移动端工程矩阵与定位

平台在移动端设立了两个针对不同应用场景的工程，名称与定位明确如下：

| 工程目录名 | 工程类型 | 核心定位与技术栈 | 开发工具 |
| :--- | :--- | :--- | :--- |
| **`doupi-miniApp`** | **微信原生小程序** | **招生宣传与在线预约轻应用**<br>基于微信原生 WXML/WXSS/JS 开发，体积轻巧，专用于微信生态内家长快速分享、查看简章与提交预约。 | 微信开发者工具 |
| **`doupi-app`** | **跨端移动 App** | **教师与教务综合移动工作台**<br>基于 **uni-app x + UTS + uvue 原生渲染** 架构，可编译打包为 Android APK、iOS App 及鸿蒙应用，具备满帧原生性能。 | HBuilderX / VSCode |

---

## 2. 微信原生端 (`doupi-miniApp`) 开发指南

### 2.1 开发者导入与运行
1. 打开 **微信开发者工具**。
2. 选择 **导入项目**，目录选择 `doupi-miniApp/`。
3. 填入学校正式的小程序 AppID（或点击使用测试号）。
4. 编译后即可预览在线预约看校、简章翻阅与校园环境导览。

### 2.2 接口网关规范
小程序端统一调用后端专属的小程序网关入口：
- 基础路径：`/api/wx/`
- 常用接口：
  - 提交预约看校：`POST /api/wx/appointment/submit`
  - 获取校区信息：`GET /api/wx/campus/list`
  - 获取最新招生简章：`GET /api/wx/banner/list`

## 3. Uni-app 移动端 (`doupi-app`) 开发指南

### 3.1 跨端架构特点
- **uvue 原生渲染**：编译后在 Android 上直达 Kotlin 原生 View、在 iOS 上直达 Swift 原生 View，没有传统 Webview 的白屏卡顿问题。
- **状态管理**：采用 Pinia 全局状态管理。

### 3.2 开发与调试
1. 启动 **HBuilderX**，点击菜单：`文件 -> 导入 -> 从本地目录导入`，选择 `doupi-app/` 目录。
2. 点击顶部菜单：`运行 -> 运行到内置浏览器` 或 `运行到 Android/iOS 模拟器` 即可开始联调。
