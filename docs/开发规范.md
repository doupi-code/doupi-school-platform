# 豆皮校园管理平台 — 开发规范

## 1. 技术栈

| 类别 | 选型 |
|:--|:--|
| 框架 | React 19 + TypeScript (strict) |
| 构建 | Vite 5+ |
| UI 库 | Ant Design 6 + @ant-design/pro-components |

## 2. 目录规范

```
src/
├── api/          # 按模块组织 API 调用（每个后端模块一个目录）
├── components/   # 通用业务组件（非页面级）
├── hooks/        # 自定义 Hooks
├── layouts/      # 布局组件
├── pages/        # 页面组件（按模块/功能组织子目录）
├── router/       # 路由配置
├── store/        # Zustand stores
├── styles/       # 全局样式和主题
└── utils/        # 工具函数
```

### 4.2 单文件行数限制

- 页面组件：**不超过 500 行**，超过则拆分子组件

## 5. API 规范

### 5.1 Web 管理端 API（RESTful）

```typescript
// api/recruit/appointment.ts
import { get, post, put, del } from '@/api/request';

// 查询列表
export const listAppointment = (params: any) => get('/recruit/appointment/list', params);
// 获取详情
export const getAppointment = (id: number) => get(`/recruit/appointment/${id}`);
// 新增
export const addAppointment = (data: any) => post('/recruit/appointment', data);
// 修改
export const updateAppointment = (data: any) => put('/recruit/appointment', data);
// 删除
export const delAppointment = (ids: number[]) => del(`/recruit/appointment/${ids.join(',')}`);
```

### 5.2 Web 用户端 API（Dispatcher 网关）

```typescript
// api/dispatcher.ts
export const dispatch = async (action: string, payload: object = {}) => {
  const { data } = await axios.post('/api/wx/dispatcher', { action, payload });
  return data;
};

// 使用示例
dispatch('appointment.create', { parentName: '张三', phone: '13800138000' });
```

## 8. 防硬编码最高规约（零容忍）

详细规约见专项文档：[07-全端技术栈与防硬编码开发规范.md](07-全端技术栈与防硬编码开发规范.md)

1. **实体与 DTO 零初值**：Java 持久化实体与查询 DTO 类绝对禁止在字段声明时赋予默认值，防止 Spring MVC 组装 GET 参数时隐式增加过滤条件；
2. **业务魔数参数化**：金额单价、折算系数、包装规格等业务数值必须纳入 `sys_config` 集中管控，通过 `selectConfigByKey` 动态读取；
3. **字典驱动下拉选项**：前端表单严禁写死 `<Option value="...">`，必须统一调用 `useDict` 动态拉取系统字典；
4. **多端环境配置外部化**：严禁在前端、移动端和小程序代码中写死 BaseURL、IP 地址、物理磁盘路径或测试密钥。

- **微信原生小程序**：微信小程序原生框架 (WXML / WXSS / JS)
