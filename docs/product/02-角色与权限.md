# 角色与权限

更新日期：2026-11-05。状态：本期产品目标；学生家长服务与家校开放日已确认P0首批待开发，现有授权需逐项验收，不代表全部已经具备。

## 1. 用途与边界

本文件规定谁可以申请、审核、办理、确认和查看校园行政及已确认的在校服务，适用于文印、物资领退、库存盘点、内部通知、基础台账、最小学生档案、分数历史、家校通知和开放日送物。角色按业务职责定义，不要求一个岗位对应一个独立人员。

部门、人员、班级、物资和套装资料以统一档案为准。新增正式学生最小档案不等于完整学籍、排课、人事手续或教学平台，不能以招生预约姓名或光荣榜替代。

## 2. 岗位职责与数据范围

| 角色 | 主要职责 | 默认可查看范围 | 关键限制 |
| --- | --- | --- | --- |
| 教职工／班主任 | 发起需求、补充资料、确认领取和归还 | 本人事项、授权负责班级的相关事项、面向本人的通知 | 不自行批准超量申请，不改库存或他人记录 |
| 行政／教务经办人员 | 受理、代录、分派、发放回收与业务核查 | 职责覆盖部门、年级或班级的事项 | 代录须注明原申请人；超出授权事项送负责人批准 |
| 文印工作人员 | 核对印刷要求、接单排期、记录领纸与损耗、交付 | 分派给本人或文印岗位的任务与必要原稿 | 不因完成印制就代替领取人确认，不因取消任务抹去实耗 |
| 总务／仓库管理人员 | 验收收发、备货、库存预警、盘点与退回检查 | 授权仓库和物资范围的单据、库存与必要领用资料 | 不最终批准本人盘点差异；损坏物资不直接计入可用库存 |
| 部门负责人／校级管理人员 | 审批例外、核定差异、协调超期与交接、查看汇总 | 所负责部门或被授权的学校范围 | 审批权限与范围明示；不得默认拥有所有原稿和联系方式 |
| 招生行政／接待人员 | 确认预约、安排接待、核销与记录沟通 | 职责范围内的预约和接待事项 | 到校核销不能替代录取、报名或缴费确认 |
| 宣传／信息发布人员 | 维护草稿、公开资讯与学校展示内容 | 授权栏目及其公开资料 | 内部办公资料不得因具有发布权限而对外公开 |
| 平台业务管理员 | 组织档案、岗位授权、基础规则和交接安排 | 配置维护所需资料 | 管理配置权限不等于业务审批、交付确认或盘点批准权限 |
| 正式学生档案／监护关系核实人员 | 建立最小学生档案，核实班主任提交关系，补录、停用与处理异常绑定 | 授权校区、年级、班级所需档案和关系 | 不因档案维护权限自动获得成绩发布或全量成绩导出权限 |
| 教务成绩处理／发布人员 | Excel导入、匹配、异常处理，按考试＋班级发布、撤回及版本更正 | 授权考试与班级的成绩、处理记录 | 未处理异常不可发布；普通员工身份不自动获得成绩权限 |
| 班主任／家校发布人员 | 收集监护人姓名手机号关系，提交核实，发布适用通知并核查回执 | 负责班级必要档案、通知及回执 | 收集资料不直接激活关系；不默认获得其他班级成绩或监护人资料 |
| 家长／有效监护人 | 查看关联孩子已发布分数、接收通知、预约开放日及本人查单 | 当前有效关联孩子的适用信息、本人创建订单 | 一人可多孩、一孩可多监护人；他人订单仅告知本人孩子已约，不泄露其他孩子或访客 |
| 家校开放日活动管理人员 | 配置场次、人数容量、适用学生和区域，停办通知与台账核查 | 授权活动和校区所需预约与人员信息 | 活动管理不赋予成绩查看权，统计不能称实时在校人数 |
| 家校开放日现场工作人员 | 核验有效凭证、按实际人员分批入校、离校登记与核实补录 | 授权活动、校区的现场必要资料 | 重复登记不重复计人；不取得无关学生档案或成绩 |
| 同行到访人员 | 按实名预约到访并当面送物 | 本次到访必要指引 | 同行身份不授予学籍、成绩、家长资格或员工权限 |

## 3. 角色协作规则

- **申请与代办**：保存原申请人、实际录入人和需求来源；申请人能查看办理进度。代录不表示经办人已替申请人确认交付。
- **审核与办理**：按事项类型、用量与学校规定确定固定审核岗位。免审批事项也须明确受理和经办责任；拒绝、退回、变更批准数量均说明原因。
- **职责分离**：盘点经办人不能最终批准本人盘点差异。需审批事项由指定负责人处理；同一人兼任相关岗位时，另行指定具备权限的复核人。
- **交付确认**：申请人、指定领取人或经明确授权的班级代表确认实际收到内容。代领记录代领人及原领取对象。
- **缺岗处理**：待办岗位无人时明确提示待分派，由有权负责人安排；不能无声跳过审批或自动视为办结。
- **岗位交接**：离职、换岗或临时代理时，列出未办事项、未确认交付和未归还物资，指定接手人并保留交接时间和原因。本期不扩展为完整入离职手续管理。
- **查看与导出**：按工作需要授权，查询、附件、报表和导出使用同一业务范围；仅有汇总查看权限不默认获得全部明细。
- **敏感资料**：原稿、试卷、人员联系方式等仅向办理所需人员开放；公开宣传资料与内部办事材料分开管理。
- **三类身份独立**：微信身份、监护资格、员工业务权限分别核实。微信登录或拥有手机号只解决相应身份验证，不能单独证明监护关系或员工权限；兼任员工的家长按当前角色分别访问。P0只开放当前有效家长对关联孩子的访问，学生本人直接访问留P2。
- **监护关系激活**：班主任收集姓名、手机号、关系，由后台校方核实后建立关联；家长完成真实本人手机号验证后激活，手输手机号不得取得成绩权限。漏名先校方补录，再发定向、限时、一次有效邀请；过期、重复、转发或对象不符不能生效。异常号码、换号与换微信须校方核实，保留处理记录。
- **当前关系与历史**：分数和家校通知访问按当前有效关系判断；关系失效或学生毕业／离校停止家长资料访问，历史内部保留。转班保留历史，已发布考试班级和通知适用学生快照不被重算；失效关系的旧回执保留，不代替现关联家长确认。
- **通知回执**：家校通知按学生形成发布范围快照；每位家长分别记录阅读和主动确认，主统计按学生至少一位当前有效监护人主动确认，不把一人确认当作全家已读。已撤销关系的旧回执保留历史，不代替现关联家长确认。
- **开放日隐私**：同孩子同活动仅一有效单；其他监护人只知本人孩子已约，不能借孩子关系查看他人订单中其他孩子或访客。同行不因入校获得学生或成绩权限。

## 4. 基础资料维护

- **组织与人员**：维护姓名、部门、岗位、在职状态和业务职责；人员停用后保留历史单据中的责任归属。
- **班级资料**：维护年级、班级、班主任及业务所需人数；人数变化不直接改写历史发放数量。
- **正式学生资料（P0待开发）**：校区、全校唯一学号、姓名、班级、入学年度、在读／毕业／离校状态，保留转班历史；同名可区分，跨校区学号也不能重复，不复用招生预约或光荣榜数据作为正式身份。
- **监护关系资料（P0待开发）**：监护人姓名、手机号、关系、对应学生、校方核实及激活／失效记录；允许一人多孩子、一孩多监护人，手机号更正与换微信保留核实依据。
- **物资与套装**：维护名称、分类、规格、计量单位、包装换算、库位、预警线和常用套装；套装变化不改写已发生记录。
- **审批与办理规则**：维护适用事项、免审批条件、需审批条件、审核岗位、经办岗位和办理时限，并记录生效范围。

## 5. 验收场景

- **AUTH-01 本人范围**：普通教职工可查看本人申请，不能查看无授权人员的申请、试卷及联系方式。
- **AUTH-02 代录留痕**：行政代录后同时显示原申请人和录入人；领取确认仍由指定领取人完成。
- **AUTH-03 独立复核**：仓管提交盘点差异后不能以同一身份完成最终批准，须由指定负责人处理。
- **AUTH-04 缺岗与交接**：原经办人停用后，未办事项进入明确的交接安排；完成交接后接手人可继续办理，原处理记录保留。
- **AUTH-05 查询与导出一致**：无权查看的人员记录，在查询、附件查看和导出中均不可取得。
- **AUTH-06 历史资料稳定**：人员改名、转岗、班级人数或套装变化后，原单据仍可核查当时的对象、批准内容与实际发放。
- **AUTH-07 关系与本人验证**：仅微信登录、手输手机号、预约姓名或转发邀请均不能获取成绩；已核实关系＋真实本人手机号验证可激活，一人多孩与一孩多监护人分别可查，失效关系不可继续访问。
- **AUTH-08 漏名与异常**：校方补录后定向、限时、一次邀请可完成激活；过期、重复使用、号码冲突或换微信未经核实均不扩大权限。
- **AUTH-09 成绩与发布范围**：家长仅当前有效关联且在读的孩子、教务仅授权考试班级；学生本人无P0查分入口，毕业／离校停止家长资料访问并内部保留历史；草稿及撤回分数不可见，跨端、附件与导出不得绕过范围。
- **AUTH-10 活动最小权限**：现场人员仅看本活动必要资料；另一监护人只能获知本人孩子已约，不能查看同单其他孩子、访客或取得成绩权限。

## 6. 试运行前需确定的业务参数

各部门审核人和替补人、免审批条件、超量标准、办理期限、可代领范围、通知范围，以及正式档案核实责任、手机号验证方式与开放日场次参数由学校确认。本文件不虚构具体限额、人员名单或生效时间；毕业／离校即停止家长资料访问、历史内部保留，参数确认不得绕过已确认的资格、发布和容量规则。
