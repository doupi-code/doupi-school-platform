# Web门户产品说明

更新日期：2026-11-05。状态：既有公开门户保留与必要完善，线上内容和预约结果须按实际场景核验；在校家长服务新范围不扩展到Web。

## 1. 用户与目标

面向家长、学生和社会访客，解决“了解学校、判断是否咨询或访校、提交需求、查询安排”四类任务。公开门户与行政后台分别承担对外服务和内部办理职责。

本文访校预约专指入学前招生游园，与在校家校开放日送物分别配置与统计。入学后的孩子关联、私密分数历史、家校通知和开放日预约由[微信小程序](03-微信小程序.md)承载，不在Web提供家长成绩入口；公开光荣榜也不能替代本人私密查分或正式学生档案。

## 2. 页面与导航

- **首页**：学校简介、关键公开信息、校园展示、资讯和访校入口。
- **学校介绍**：办学理念、校区信息、校园环境及公开联系方式。
- **师资与校园生活**：正式发布的教师、设施、生活服务等资料。
- **招生信息**：招生说明、常见问题、咨询方式和预约指引。
- **公开资讯**：资讯列表、详情、发布日期和适用说明。
- **访校预约**：联系人、来访对象、期望日期时段、咨询需求和提交结果。
- **预约查询**：通过适当身份核验查看本人预约、确认状态、接待安排和有效凭证。

既有栏目可沿用，不为本轮行政流程改造整体重建门户视觉和内容体系。

## 3. 功能清单

- **公开内容浏览（保留）**  
  **适用角色：**家长、学生及社会访客。  
  **操作流程：**进入栏目 → 查看正式内容 → 通过联系方式或预约入口进一步咨询。  
  **业务价值：**统一学校对外口径，减少重复询问。
- **访校预约（保留与统一）**  
  **适用角色：**家长、学生、招生人员。  
  **操作流程：**查看可预约日期与规则 → 提交必要联系和需求信息 → 得到预约号 → 等待招生确认。  
  **业务价值：**让来访需求进入学校接待台账。
- **本人预约查询与取消（按既有能力核查）**  
  **适用角色：**预约联系人。  
  **操作流程：**核验本人身份 → 查询状态与凭证 → 查看取消指引或办理取消 → 查询最终结果。  
  **业务价值：**减少反复电话查询和无效来访。

## 4. 用户主流程

访客进入学校公开页面 → 查看学校及招生资料 → 打开访校预约 → 填写必要信息并确认 → 取得预约号 → 招生办核实并确认安排 → 联系人查询有效凭证和接待信息 → 到校后由工作人员核销 → 本人可查询到校状态。

## 5. 业务规则与验收

- 未经确认的预约明确显示待确认，不承诺已经安排接待。
- 与小程序采用相同预约规则；后台取消或更正后，门户查询反映同一结果。
- 查询须防止仅凭他人手机号取得联系方式、学生资料或核销凭证；所需身份核验与错误次数限制由统一安全规则确定。
- 草稿、内部通知、未授权试卷及行政台账不得作为公开内容展示。
- 正式内容显示真实来源与更新时间；默认或示例内容不伪装成最新公告、招生承诺或实际成绩。
- Web本期不提供学生学习、私密成绩查询、在校家校通知确认、开放日送物预约、录取缴费或内部行政审批；此处端边界不否定已确认P0小程序在校服务。
