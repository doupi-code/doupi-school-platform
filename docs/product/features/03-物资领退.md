# 物资领退

版本：2026-11-03  
规划状态：静态核查，未验收上线。文中“已有”仅表示已核查到相应业务能力，不代表已通过现场业务验收；“本期目标”表示本次规划要求。

## 1. 用途与边界

将教师办公用品、学生教材和班级公共物资的申请、发放、缺货补发、领取确认及归还转为可跟踪的行政事项，回答谁申请、实际领了什么、还缺什么、归还了多少以及由谁经办。

本模块管理日常领退和教学物资套装，不承担固定资产折旧、财务报销或完整采购管理。发放与归还以真实实物交接为依据，与库存管理使用一致的收发事实。

## 2. 参与角色

- 申请人：教师、学生事务经办人或班级负责人，提出用途、对象、物品及数量，补充说明并跟踪结果。
- 行政受理人：核对领用对象、班级和申请明细，判断是否需要审批，安排发放和补发。
- 审批人：按学校授权确认领用范围、数量及特殊申请，说明退回或不予办理原因。
- 物资经办人：核对可用数量、备货、记录实际发出及接收归还，处理实物差异。
- 领取或归还人：核对实际交接数量与状态，确认领取或归还；代办时说明对应教师、学生或班级。
- 行政负责人：处理历史归还、异常损坏及争议，查看未补发、未签收和应归还事项。

## 3. 现有能力与差距

- 已有：面向教师、学生和班级登记发放与回收，记录业务场景、年级、学科、物品、数量、经办人和可选照片凭证。
- 已有：可维护教学办公用品、教材及班级物资套装，领用时引用套装明细。
- 已有：发放时扣库存；回收时对完好或可再用物品增加库存；可撤销领退登记，并查看个人、班级及单品台账和统计。
- 差距：当前主要登记已经发生的领退，缺少申请、审批、备货、部分发放、缺货待补和领取人确认。
- 差距：归还未与原领用事实形成完整对应，不能可靠区分原来领了多少、累计归还多少、还应归还多少。
- 差距：领退记录、出入库流水及撤销处理尚不能认定已经实现一致对账，本期需建立统一业务口径。

## 4. 功能需求

- **MAT-01 领用申请与代录【本期目标】**。适用角色：申请人、行政受理人。操作流程：选择领用对象、用途、班级或部门、物品和申请数量，可引用套装后逐项核对；当面申请由经办人代录并说明来源。业务价值：保留需求依据，减少口头申请遗漏。
- **MAT-02 受理与授权审批【本期目标】**。适用角色：行政受理人、审批人。操作流程：核对对象及重复申请情况，按学校授权批准、退回补充或不予办理；形成获准数量和原因。业务价值：明确发放依据，避免以库存充足替代领用授权。
- **MAT-03 备货与缺货待补【本期目标】**。适用角色：行政受理人、物资经办人。操作流程：核对可用库存，列明可发和缺货数量；可发部分进入交接，缺货部分保留待补数量和负责人，并在有货后继续安排。业务价值：允许先发急需物品，同时确保欠发数量不被遗漏。
- **MAT-04 分次发放与领取确认【已有发放登记基础，本期完善】**。适用角色：物资经办人、领取人。操作流程：按本次实际发出数量办理交接，物品实际发出时扣库存；领取人核对后确认收到，可由指定人员代领；各次发放累计回到原申请。业务价值：区分申请、批准、实发和签收，支持部分交付。
- **MAT-05 套装与个人、班级清单【已有基础，本期完善】**。适用角色：行政受理人、物资经办人。操作流程：按适用对象、年级及学科选择套装，核对本次清单；分别展示每个物品的获准、实发、缺货和归还情况。业务价值：提高开学和入职集中发放效率，避免套装中某件缺货被总数量掩盖。
- **MAT-06 关联原单归还【已有回收登记基础，本期新增对应关系】**。适用角色：归还人、物资经办人。操作流程：从原领用清单选择物品和本次归还数量，核对累计实领及已归还量，记录完好、可再用或损坏状态；验收接收后更新归还清单，可用物品增加库存。业务价值：清楚记录归还来源和应归还余额。
- **MAT-07 取消、错发和异常处理【已有撤销基础，本期完善】**。适用角色：行政受理人、物资经办人、行政负责人。操作流程：取消尚未发出的剩余数量；已发出部分按实物追回、归还或核实更正处理；损坏、遗失、拒收及数量争议说明原因、责任人和处理结论。业务价值：防止以取消单据代替实物退回。
- **MAT-08 领退待办与对账【已有台账基础，本期完善】**。适用角色：行政受理人、行政负责人。操作流程：查看缺货待补、已发待签收、待验收归还、应归还及异常事项；按个人、班级、物品和期间核对净发放及库存流水。业务价值：把未办结事项持续呈现，并保持台账与实物去向一致。

## 5. 流程与状态

现有主要是正常、已撤销两类领退登记状态，不能据此推定已经存在申请和签收流程。

本期领用流程为：草稿 → 待受理或审批 → 待发放 → 部分发放 → 已完成。需要补充时退回；未发出的全部或剩余需求可以取消。每项物品同时明确缺货待补、本次已发待签收及累计已签收数量。

本期归还流程为：选择原领用清单 → 待交接或验收 → 已验收归还；数量或状态有争议时进入待处理。一次领用可以分次发放，也可以分次归还。

一份申请中部分物品完成、部分物品缺货时，整份申请保持未办结，直至全部获准数量已经签收或剩余需求明确取消。领用完成不代表应归还物品的归还义务已经结束。

## 6. 业务规则

- 分别记录申请数量、获准数量、累计实发数量、累计签收数量、待补数量和已取消数量，不以一个总数量代替各阶段事实。
- 实际发出数量不得超过获准但尚未发出的数量，也不得超过可用库存；缺货可以保留待补，不能发出不存在的库存。
- 申请、审批和备货不代表实物已经发出。实物发出确认时扣库存，领取确认用于核实交接，不能再次扣库存。
- 套装是清单参考。实际发放及缺货按单品记录，不能因为套装部分发出就认定整套已交付。
- 归还应关联原领用对象和物品；本次归还数量不能超过原单累计实领减去累计已确认归还的数量，不能重复归还。
- 应归还数量以实际领用和已确认归还为依据；损坏物品确已接收时记录实物归还事实，但是否免除责任另按学校规定处理。
- 实物归还完成与归还责任结清分别跟踪；已接收损坏物品但责任尚未核定时，仍保留责任处置待办，不能自动标为全部结清。
- 只有完好或可再用且验收接收的归还品增加可用库存。损坏、报废或遗失不能作为完好库存增加；已经消耗的物品不能伪记为完好归还。
- 取消未发数量不改变库存；已经发出的物品必须确认实物追回或完成经核实的登记更正，不能因申请取消直接增加库存。
- 历史归还无法找到原单时，由行政负责人核准来源、对象和数量并单独说明，不能虚构一次新领用来代替来源。
- 每笔实际发放、归还和经批准的更正，应在个人或班级清单、领退台账及库存流水中表达同一数量和同一业务结果，不重复计算。

## 7. 验收场景

以下数量均为验收示例，非学校真实数据。

- **MAT-A01 部分发放与补发**：申请并获准20本教材，可用库存仅12本。实际发出12本后库存为零，原申请显示实发12本、缺货待补8本。后续有货并补发8本、完成领取确认后，累计实发及签收均为20本，待补为零；第一次发放不能使申请提前完成。
- **MAT-A02 套装单品缺货**：一套办公用品含笔2支、笔记本1本，笔可以发齐但笔记本缺货。确认发笔后仍保留笔记本1本待补，不能显示整套已完整领取。
- **MAT-A03 原单分次归还**：原单实际领用5件应归还物品，第一次确认归还2件，第二次最多可归还3件；再次提交4件或对已归还的2件重复办理时，应明确指出超出可归还量，不能增加库存。
- **MAT-A04 损坏归还不增加可用量**：原单领用3件，本次归还2件，其中1件完好、1件损坏。确认接收后累计实物归还2件，尚有1件未归还；可用库存只增加1件，损坏物品进入待处置或责任处理记录。
- **MAT-A05 取消剩余需求**：获准20件，已实际发出并签收12件，剩余8件不再需要。取消剩余8件后库存不变，12件实领记录保留；只有真实归还其中物品并验收后才增加对应可用量。
- **MAT-A06 发出与签收分开**：实际发出10件后已扣库存，但领取回执尚未确认。经办人能够在待签收清单中找到10件；领取确认后库存不再扣减，台账只计一次发出。
- **MAT-A07 领退与库存一致**：实际发出10件，随后关联原单完好归还3件。个人清单和领退统计均可解释净发出7件，库存相对发放前净减少7件，流水保留发出10件和归还3件两次真实交接。
- **MAT-A08 损坏责任未结**：应归还3件均已交回，其中1件损坏且责任待核定。实物未还数量可以为零，可用库存只增加完好的2件，损坏责任待办仍保持未结；有权人员记录处置结论后才结清归还责任。
