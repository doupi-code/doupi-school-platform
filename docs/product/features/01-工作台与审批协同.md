# 工作台与审批协同

更新日期：2026-11-03。状态：P0 产品目标，当前仅完成静态梳理；本文件不表示功能已验收上线。

## 1. 用途与边界

为行政事项提供统一的申请、受理、审核、分派、办理和结果查询入口。首先支持文印、物资领退及库存差异处理，采用学校已明确的固定流程。本期不建设任意流程设计、多部门复杂会签或完整人事审批。

## 2. 参与角色

- 申请人：发起、补充、查询、撤回以及确认结果。
- 行政经办人员：受理、代录、分派、协调异常和交接。
- 审核负责人：在授权范围批准、拒绝或退回。
- 实际经办人：接单、更新办理进展、提交交付结果。
- 平台业务管理员：维护岗位与职责，不代替业务责任人批准或确认。

角色和资料范围详见[角色与权限](../02-角色与权限.md)。

## 3. 现有能力与差距

已有工作台、业务统计、部分提醒和公告入口，但部分内容为示例或固定提示。文印、领退与库存虽有独立登记和状态，尚未形成统一的“我的申请、待我处理、我经办、已办事项”。

本期补齐真实待办、固定审批、接单、责任交接与事项记录。新增目标不能仅凭页面有入口或按钮判定完成。

## 4. 功能需求

- **COL-01 个人事项工作台**  
  **适用角色：**全部内部用户。  
  **操作流程：**进入工作台 → 按我的申请、待我处理、我经办、已办查询 → 查看事项与下一步 → 完成对应动作。  
  **业务价值：**集中展示本人实际工作，减少在不同业务间重复查找。

- **COL-02 受理与代录**  
  **适用角色：**申请人、行政经办人员。  
  **操作流程：**本人提交或登记线下来源 → 核对资料 → 受理或退回补充 → 进入固定办理路径。  
  **业务价值：**兼容现有办公习惯，同时保留原申请人、录入人和需求来源。

- **COL-03 固定规则审批**  
  **适用角色：**申请人、审核负责人。  
  **操作流程：**识别事项是否需审批 → 明确审核岗位 → 通过、拒绝或退回补充 → 记录意见与批准范围。  
  **业务价值：**超量及特殊事项有明确授权，低值高频事项保持简洁。

- **COL-04 经办接单与责任交接**  
  **适用角色：**行政经办人员、实际经办人、部门负责人。  
  **操作流程：**分派任务 → 经办人接单并确认期限 → 更新办理进度 → 缺岗或变动时交接给指定人员。  
  **业务价值：**每个未结事项都有当前责任人，避免任务停留在无人认领的环节。

- **COL-05 补充、撤回与变更处理**  
  **适用角色：**申请人、审核负责人、经办人。  
  **操作流程：**提出补充或变更 → 说明原因 → 根据是否已审批、已执行判断重新审核或确认处置 → 保留前后内容。  
  **业务价值：**防止已批准或已执行内容被无记录地覆盖。

- **COL-06 时限与异常协调**  
  **适用角色：**经办人、行政经办人员、部门负责人。  
  **操作流程：**确认办理期限 → 查看待接单、缺货、待补资料、待领取和超期事项 → 明确后续责任人与处理安排。  
  **业务价值：**及时识别停滞事项，使延期和异常有解释、有安排。

## 5. 流程与状态

一般路径：草稿 → 待受理 → 待审批（需要时）→ 待接单 → 办理中 → 待确认 → 已办结。

- 退回补充：说明缺失内容，申请人补齐后重新提交。
- 审批拒绝：保留决定和理由；需要重新申请时关联原事项，不覆盖原决定。
- 待补货、待资料等：说明具体原因、当前责任人和后续动作，处理后返回相应环节。
- 撤回／取消：说明原因，先判断是否已实际执行；已发生收发或消耗按所属业务处理。
- 各业务使用对应的具体状态，通用工作台显示其当前阶段，不能把“印制完成”“通知已读”统一视为事项办结。

## 6. 业务规则

- 待办必须关联实际未完成事项，并显示申请人、业务类型、当前环节、责任人、提交时间和办理期限。
- 办理成功、失败和未取得结果分别表达；不能用演示数据、预设成功或虚构通知填补缺失记录。
- 免审批依据须明确；需要审批而未找到审核人时停留待分派，不跳过审批。
- 已审批内容的数量、用途或关键要求发生变化时，依规则重新确认或审核，并保留变更依据。
- 处理记录包含动作、处理人、时间、意见和必要凭证。接手人能够查看此前材料及未结问题。
- 重复提醒不产生新的业务申请或重复收发。相同事项重复提交时应提示检查；确需重办时说明原因。
- 交付确认按实际领取对象完成。经办完成与接收确认分别记录，不以打开消息代替交付确认。
- 固定流程的岗位、限额和期限由学校确认；不在产品文档预设人员或金额。

## 7. 验收场景

- **COL-A01 真实待办**：一个待审批事项出现在指定审核人的待办，其他无关人员不可见；审批后从原待办移除并进入下一责任岗位。
- **COL-A02 无记录**：没有业务或未取得结果时明确显示对应状态，不显示虚构人数、效能分、通知或“办理成功”。
- **COL-A03 免审批**：满足已确定条件的领用直接进入受理和发放；超出条件则送审核，不能通过代录绕过。
- **COL-A04 退回补充**：申请人看到明确缺失项，补齐后沿原事项继续办理，原退回意见可查。
- **COL-A05 缺岗交接**：经办人停用后事项不消失，指定接手人后能继续办理，交接前后责任记录完整。
- **COL-A06 执行后取消**：已发生领纸或发放的事项取消时，先处理实际消耗、实物退回或差错，不直接恢复全部库存。
- **COL-A07 领取确认**：经办人提交完成结果后仍显示待确认；指定领取人确认实际数量后才按业务规则办结。
