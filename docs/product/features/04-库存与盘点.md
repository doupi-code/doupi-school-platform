# 库存与盘点

版本：2026-11-03  
规划状态：静态核查，未验收上线。文中“已有”仅表示已核查到相应业务能力，不代表已通过现场业务验收；“本期目标”表示本次规划要求。

## 1. 用途与边界

为行政人员提供可核对的物品档案、收发记录、可用库存、低库存事项和周期盘点，使库存数字能够解释为实际收发与经审核调整的结果。

本模块覆盖教师办公用品、教材、文印耗材等教学行政物资，管理到货验收后的入库、实际发出、可用归还、损耗及盘点差异。采购合同、付款报销、固定资产折旧及财务总账不在本模块范围内。

## 2. 参与角色

- 物资经办人：维护物品信息，核对到货和收发实物，登记数量、单位、存放位置及凭证。
- 行政受理人：从领用、文印等事项查看所需物资和缺货情况，跟进待补事项。
- 盘点人：在确定范围和基准时点后清点实物，记录实盘数、差异原因及复盘结果。
- 独立复核人：核对盘点依据、期间收发和差异处理，不得批准自己经办的盘点结果。
- 行政负责人：安排盘点和复核人员，处理重大或无法解释的差异，查看库存与物资管理报表。

## 3. 现有能力与差距

- 已有：物品及供应商档案、分类、规格、单位、存放位置、库存下限、包装换算及散张余量。
- 已有：入库和出库登记、数量校验、正常单作废及相应库存调整，查询收发流水、库存概览和月报。
- 已有：低库存物品筛选和预警数量统计，尚未形成完整补货办理事项。
- 已有：全量或分类盘点，登记账面数、实盘数和差异；盘点提交后待审核，审核后按实盘数调整库存，待审核单可作废。
- 差距：盘点人和审核人尚未形成明确的独立复核约束；差异说明、退回复盘及审核证据不完整。
- 差距：盘点期间发生的正常收发，不能被默认视为已经纳入审核后的库存结果。
- 差距：领退回收、撤销等业务与库存流水的对账尚未完整闭环；库存余额与各类台账必须统一解释。

## 4. 功能需求

- **INV-01 物品与计量口径【已有基础，本期完善】**。适用角色：物资经办人、行政负责人。操作流程：维护名称、分类、规格、包装单位、基础单位、换算关系、位置和库存下限；收发及盘点时同时明确整包与零散数量。业务价值：避免同一物品因单位不一致而重复或少记。
- **INV-02 到货验收与入库【已有入库基础，本期完善】**。适用角色：物资经办人。操作流程：核对来源、供应商、实际到货和验收合格数量，记录短缺、破损及待处理数量；只对验收接收的可用物资办理入库。业务价值：库存体现实际收到且可使用的数量。
- **INV-03 统一收发与更正【已有基础，本期完善】**。适用角色：物资经办人、行政负责人。操作流程：按实际发出、可用归还、余纸退回及经批准的更正记录数量与来源；对已发生实物收发的事项核实后处理撤销或更正。业务价值：让领退、文印、出入库和库存余额能相互核对，避免漏记或重复记账。
- **INV-04 低库存与补货跟进【已有预警基础，本期完善】**。适用角色：行政受理人、物资经办人、行政负责人。操作流程：查看低于下限和已有待补需求的物品，明确跟进人、预计到货及处理结论；到货入库后继续安排原缺货事项。业务价值：把缺货提醒转为有人负责的工作。
- **INV-05 盘点准备与实物清点【已有基础，本期完善】**。适用角色：盘点人、行政负责人。操作流程：确定范围、基准时点、盘点人和复核人，登记当时账面数量；逐项清点整包与零散数量，说明盘盈、盘亏及异常，必要时补充凭证。业务价值：形成有明确时间和范围的盘点依据。
- **INV-06 盘点期间收发核对【本期目标】**。适用角色：盘点人、物资经办人、独立复核人。操作流程：保留基准时点之后、审核之前的相关收发记录，核对其是否已经体现在实盘数量中；确认差异归属，必要时复盘后再提交。业务价值：避免以较早的清点数量覆盖后来真实发生的入库或发出。
- **INV-07 独立复核与调整批准【已有审核基础，本期完善】**。适用角色：独立复核人、行政负责人。操作流程：由未经办该次盘点的人核对差异原因、数量和期间收发；批准后形成盘点调整，退回时说明需要复盘或补充的事项。业务价值：让盘点调整经过独立判断，保留责任和审批依据。
- **INV-08 盘点归档与后续更正【本期目标】**。适用角色：盘点人、独立复核人、行政负责人。操作流程：审核通过后保存本次范围、账面数、实盘数、差异、原因及批准结果；发现错误时发起有原始依据的复核或更正，单独审批。业务价值：避免已批准结果被无痕改写或重复调整。
- **INV-09 库存与收发对账【已有报表基础，本期完善】**。适用角色：物资经办人、行政负责人。操作流程：按物品和期间查看期初、实际入库、实际发出、可用归还、已批准盘点调整及期末；追查来源事项及未结异常。业务价值：让库存变化可解释，不能把计划需求当成实际收发。

## 5. 流程与状态

现有入库和出库主要区分正常、已作废；盘点主要区分待审核、已审核、已作废。

本期收货流程为：待验收 → 部分验收或验收完成 → 按合格实收数量入库；差异部分继续待处理。实际发出、归还及文印余纸退回按相应事项完成实物交接后记录。

本期盘点流程为：待安排 → 盘点中 → 待复核 → 已批准归档。复核人可以退回补充或复盘；复盘完成后重新提交。尚未批准且决定不再继续的盘点可以取消，取消不改变库存。

盘点中和待复核阶段如发生正常收发，盘点事项应继续呈现这些变化及其核对结论。批准前有未解释差异或期间收发未核清的，保持待处理，不能直接调整结案。

## 6. 业务规则

- 统一基础单位和包装换算后再比较数量。纸张等可拆零物资盘点必须覆盖散张，不能只清点整包数量。
- 计划采购量、领用申请量及预计印刷用纸，不等于实际入库、实际发出或实际耗用，不直接改变可用库存。
- 入库依据验收接收数量；发出依据实物交接数量；归还依据验收后的可用数量。签收回执和完工核销不能使同一次实物收发重复计算。
- 已发出但尚未收到领取回执的物资仍属于已经离开仓库的实物，应同时出现在发出记录和待签收清单中，不能漏计。
- 作废或取消只终止业务事项，不自动证明实物已经退回。已耗用物资不能因作废重新增加为可用库存。
- 盘点须明确基准时点。期间收发要逐项确认与实盘数的关系；审核调整必须保留这些真实变化，不能简单沿用过时的数量。
- 盘点人不能批准自己经办的同一盘点。没有独立复核人时保持待复核，由行政负责人另行安排，不能自动通过。
- 复核时记录复核人、时间、结论和差异处理意见；退回需说明理由，盘点人完成补充或复盘后重新提交。
- 只有审核批准的盘点差异可以影响正式库存；提交、退回、取消及尚未批准的实盘数不改变正式库存。同一批准结果不得重复调整。
- 已批准盘点不直接删除或改写。发现错误应保留原结果，重新复核并形成有原因、有批准依据的更正。
- 实盘数、实际收发数量和可用库存不得为负；无法解释的缺失、破损或待处理物品单独列明，不能包装成正常可用库存。
- 库存报表应能以期初数量，加实际接收入库和可用归还，减实际发出，再结合已批准调整，解释期末数量；文印实耗另用于分析领出纸张去向，不再重复计一次仓库发出。

## 7. 验收场景

以下数量均为验收示例，非学校真实数据。

- **INV-A01 按验收合格量入库**：计划到货100件，实到90件，其中85件合格、5件破损待处理。确认后可用库存只增加85件，短缺10件与破损5件可分别查看，不能增加100件或90件。
- **INV-A02 包装与散张盘点**：一种纸张每包500张，账面为1包加30张，即530张；实盘为1包加20张，即520张。盘点差异为少10张，不能只比较1包而认定没有差异。
- **INV-A03 独立审核**：甲完成并提交盘点后，甲不能批准该盘点；乙可查看甲的清点结果、差异原因和期间收发后批准。尚未批准前正式库存不因实盘数改变，批准后只执行一次调整。
- **INV-A04 期间发出不被覆盖**：盘点基准时点账面100件，实盘98件；之后正常发出5件，当前账面95件。审核时应核清少2件的差异以及后续发出5件，批准后的正确库存为93件；不得直接改为98件而抹掉期间发出。
- **INV-A05 退回复盘**：一项差异没有原因或凭证，复核人说明理由退回；库存保持不变。盘点人补充复盘结果后重新提交，复核人能够看到补充内容及重新确认的数量。
- **INV-A06 取消未批准盘点**：待复核盘点提出少10件，随后取消。正式库存不得减少10件，取消原因和原盘点记录可追溯。
- **INV-A07 收发与文印核销一致**：期初纸张1000张，实际领纸220张后可用库存780张；核销实耗208张时库存保持780张；可用余纸12张验收退回后库存792张。库存报表显示发出220张、退回12张，文印报表显示实耗208张，两者能共同解释纸张去向。
- **INV-A08 已批准结果更正**：已经批准的盘点发现清点错误时，不能直接删改原批准结果；应能从原盘点发起复核或更正，说明原因并由独立人员批准，原结果及更正后的变化均可查看。
