# 招生接待与门户维护

更新日期：2026-11-05。状态：既有业务保留与必要衔接，P1为后续目标；本次静态核查不代表已完成线上业务验收。

## 1. 用途与边界

招生接待帮助招生办统一收集访校需求、确认行程、安排接待、记录到校和沟通情况；门户维护帮助宣传及校务岗位统一更新对外信息。两项业务保留在行政办公产品中，由对应岗位办理。

本文访校预约专指入学前招生游园。2026-11-05已确认的P0在校[家校开放日送物](08-家校开放日送物预约.md)是独立活动：基于正式学生与有效监护关系，按实名到访人数占位、有名额即成功、到校当面送物；它不沿用招生待确认、预约学生姓名或招生凭证作为在校资格。两类活动分别配置、编号、核验与统计，招生预约不产生学籍或成绩权限。

本期以既有预约台账、预约开放日期／时段／限额设置、现场核销和门户内容维护为基础，先明确责任、状态和记录口径。回访任务、接待人员排班、改期联动及内容审核列为 P1，属于后续新增或完善需求。

到校核销只表示访客已到校，不表示报名、录取、缴费或入学。本功能不扩展为完整招生客户管理、营销投放、佣金结算、招生排名绩效、录取分班或收费退款系统。

## 2. 参与角色

| 角色 | 主要职责 |
|---|---|
| 家长或学生 | 提交访校需求，核对预约信息，查询进度和到校凭证，申请取消 |
| 招生办工作人员 | 核对联系信息，确认行程，维护预约台账，指定接待人员 |
| 接待或现场工作人员 | 查看当日安排，核验凭证，登记到校，记录接待情况 |
| 招生负责人 | 查看预约和到校情况，协调接待资源；后续安排排班和回访 |
| 宣传或校务内容维护人员 | 编辑门户资讯、校务公告及基础介绍，检查展示内容 |
| 内容审核人员 | P1：复核拟发布内容，提出修改意见或同意发布 |

## 4. 功能需求

本期仅保留既有业务并统一必要的责任、状态和信息口径，不新增完整招生或宣传管理体系；P1为后续目标。既有基础仍须核查，不能直接视为全部满足。

- **REC-01 访校预约登记与查询（既有业务保留）**  
  **适用角色：**家长或学生、招生办。  
  **操作流程：**填写学生及联系人、期望日期时段和需求 → 提交 → 获得预约号 → 查询进度与凭证。  
  **业务价值：**汇总来访需求，减少电话和聊天中的信息遗漏。

- **REC-02 预约确认与接待安排（既有业务保留，统一口径）**  
  **适用角色：**招生办、接待人员。  
  **操作流程：**查看新预约 → 联系确认 → 指定接待人员 → 形成待到校安排。  
  **业务价值：**明确每次来访由谁负责，避免无人接待。

- **REC-03 取消与异常处理（既有业务保留）**  
  **适用角色：**家长或学生、招生办。  
  **操作流程：**发起取消 → 记录原因和办理人 → 更新安排；时间有变时仅保留招生办人工核实并更正既有预约资料，改期申请与排班联动放P1。  
  **业务价值：**保持台账与实际行程一致。

- **REC-04 到校核验与接待记录（既有业务保留）**  
  **适用角色：**现场及接待人员。  
  **操作流程：**出示凭证 → 核对预约与必要身份信息 → 登记到校 → 补充沟通备注。  
  **业务价值：**留存接待事实及交接信息。

- **REC-05 接待台账与基础统计（既有业务保留）**  
  **适用角色：**招生办、招生负责人。  
  **操作流程：**按日期、状态和接待人员查看台账 → 查询明细或导出 → 查看预约及到校情况。  
  **业务价值：**支持日常协调和工作复盘。

- **REC-06 回访与未到访跟进（P1，拟新增）**  
  **适用角色：**招生人员、招生负责人。  
  **操作流程：**从接待或未到访记录创建回访 → 指定负责人及时间 → 提醒 → 记录结果并结束或继续跟进。  
  **业务价值：**防止回访遗漏，明确下一步责任。

- **REC-07 接待排班与容量管理（P1，拟完善）**  
  **适用角色：**招生负责人、接待人员。  
  **操作流程：**沿用既有开放日期、时段与预约限额设置 → 增加接待人员排班 → 安排预约 → 联动处理人员冲突、改期及专门提醒。  
  **业务价值：**避免预约集中和人员冲突。

- **CMS-01 门户资讯与校务公告维护（既有业务保留）**  
  **适用角色：**内容维护人员。  
  **操作流程：**编辑标题、分类、署名和正文 → 预览 → 保存草稿或发布 → 必要时修改或撤下。  
  **业务价值：**统一对外信息，及时纠正过时内容。

- **CMS-02 门户基础资料维护（既有业务保留）**  
  **适用角色：**内容维护人员。  
  **操作流程：**维护联系方式、学校介绍、师资、设施、常见问题及导航页脚等资料 → 检查展示 → 保存发布。  
  **业务价值：**减少多处信息不一致。

- **CMS-03 内容送审与复核（P1，拟新增）**  
  **适用角色：**内容维护人员、审核人员。  
  **操作流程：**草稿送审 → 核对事实及口径 → 退回修改或批准 → 发布并保留处理记录。  
  **业务价值：**明确内容责任，降低错发风险。

- **REC-08 预约开放规则设置（既有业务保留）**  
  **适用角色：**招生负责人、授权招生办人员。  
  **操作流程：**维护可预约日期、时段、预约限额及是否前置确认 → 核对对外可选内容 → 以同一规则受理预约。  
  **业务价值：**保持预约入口与学校实际接待规则一致；不将既有设置误计为新增排班能力。

## 5. 流程与状态

### 招生接待

目标流程：提交预约 → 待确认 → 已确认待到校 → 已到校 → 接待记录完成。家长取消或经招生办确认取消时，记录转为已取消；本期人工核实并更正预约资料后，核对当前安排和家长可见信息。

既有管理台账包含待审核、待核销、已核销、已取消。产品中分别按待确认、已确认待到校、已到校、已取消理解，需统一各入口的实际含义。接待记录完成是记录要求，不代表当前已有独立状态。

P1 增加改期申请、预约容量校验与接待人员排班联动、专门提醒，以及未到访识别和待回访、回访中、已结束的任务状态；回访结果与预约状态分开，不能通过修改到校事实代替跟进记录。

### 门户内容

既有流程为草稿 → 发布；修改或撤下已发布内容时，应清楚告知对外展示结果。P1 增加待审核、退回修改和审核通过等环节，并保留处理人与意见。既有“保存草稿”不能视为已完成审核流程。

## 6. 业务规则

- 预约须保留可核对的联系人、来访对象、日期时段、责任人和当前状态；各入口使用一致的确认口径，不能向家长承诺尚未确认的安排。
- 预约老师、指定接待人员与实际办理核销人员可以不同，应分别表达其职责，不用一个姓名替代全部责任。
- 取消及人工更正预约资料须保留原因与处理记录；P1的完整改期与排班调整沿用相同留痕要求。已取消预约不得继续当作有效入校安排；重复核销应提示已办理，不能重复计入到校数量。
- 家长查询只展示其有权查看的预约；招生人员按工作职责查看和办理。导出与统计同样受工作范围限制。
- 预约凭证和核销记录只证明预约、来访事实，不能代替学生正式报名、录取或财务凭证。
- 统计须明确日期和口径，区分新增预约、计划到访和实际到校；不能把到校率称为报名率或录取率。
- 内容维护须区分对外公告与内部通知。发布对外公告不代表教职工已经阅读或完成签收。
- 联系方式、备案信息和对外承诺须有明确维护责任；失效或过时信息应及时修正。正式展示应使用核实的资料，示例内容不能冒充真实公告、成绩或业务统计。
- 移动页面仅作为使用入口。只有任务能够真实办理、结果可再次查询且异常有明确反馈，才可计入已完成能力；示例待办、列表和成功提示不作为交付证据。

## 7. 验收场景

### 本期保留业务核查

- **REC-A01 预约规则一致**：家长完成一次预约后，能够查询相同预约号、日期时段、状态及有效凭证；官网与小程序对同一业务状态的含义一致，开放日期、时段和限额按已确认规则生效。
- **REC-A02 确认与接待责任**：招生办能够核对新预约、明确接待责任人并查询当日安排；联系未确认时不会显示为已安排接待。
- **REC-A03 取消与资料更正**：取消后，家长和工作人员看到一致结果；人工核实更正日期后双方可见安排一致；已取消或已核销凭证再次办理时有明确反馈。本期不要求完整改期申请流程。
- **REC-A04 真实核销**：现场核销形成真实到校记录，包含时间和办理人；失败不会显示成功，重复操作不会增加到校数量。
- **REC-A05 接待记录与统计**：接待人员能够补充沟通备注，其他有权人员可查询；统计明细与台账一致，且未混入报名、录取或缴费结论。
- **CMS-A01 草稿与发布**：内容维护人员能够保存草稿、预览、发布及修改门户内容；正式展示与已确认内容一致，未发布草稿不会被当作正式公告。
- **REC-A06 查看与导出范围**：角色只能查看和办理职责范围内事项；家长查询与台账导出不会暴露无关人员资料。
- **REC-A07 移动结果核查**：保留业务按真实任务逐项验证，无法完成的入口明确标示状态，不用示例数据证明已完成；不要求本期交付完整移动办公。

### 后续 P1

- **REC-A08 回访跟进**：回访任务能够明确负责人、到期时间和结果；未完成任务可继续跟进，关闭后仍保留过程记录。
- **REC-A09 排班与改期联动**：人员排班调整能够发现满额或人员冲突，改期申请确认后同步安排并提醒相关人员。
- **CMS-A02 内容审核**：内容送审能够经过退回、修改、批准和发布，保留审核人及意见；未经批准的内容不能绕过约定发布。
