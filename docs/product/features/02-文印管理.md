# 文印管理

版本：2026-11-03  
规划状态：静态核查，未验收上线。文中“已有”仅表示已核查到相应业务能力，不代表已通过现场业务验收；“本期目标”表示本次规划要求。

## 1. 用途与边界

将教师通过当面、微信等方式提出的印刷需求，转为行政人员可以受理、安排、跟进和核对的文印事项，形成从需求确认到印品领取的完整记录。

本模块管理原稿、印刷要求、办理进度、领纸、实际耗用、余纸退回、印品交接及异常。原稿内容的学术审查、考试组织及学生成绩管理不在本模块范围内。纸张收发结果与库存管理共同使用，不能分别形成相互矛盾的数量。

## 2. 参与角色

- 申请人：提出用途、印刷要求和期望完成时间，确认原稿及变更，领取或指定他人领取印品。
- 行政受理人：补全需求、核对教师和班级、安排办理顺序，跟踪待办及异常。
- 审批人：按学校授权核准需求、超额用纸、加急或特殊事项，并说明退回原因。
- 文印执行人：确认最终原稿，登记实际领纸、印刷结果、损耗、余纸和交接数量。
- 物资经办人：核对实物领纸、补领和余纸退回，确认可用库存变化。
- 领取人：核对印品名称、版本及数量，确认实际收到的印品。
- 行政负责人：查看未结事项、用纸统计及异常原因，处理争议和历史更正。

## 3. 现有能力与差距

- 已有：文印登记、教师和班级关联、原稿附件、份数和页数、单双面及颜色要求、印刷效果图片、完成和作废、错印损耗登记、台账及用纸统计。
- 已有：可从微信截图、聊天文字及导出记录中提取候选信息，可辅助识别文件页数；信息仍需经办人核对。
- 已有：登记时按测算耗纸量扣库存，并计入模板用纸、预览用纸各一张；可记录关联的耗材出库。
- 差距：预计、实领、实耗和余纸尚未独立表达；现有完成状态不等于领取人已签收。
- 差距：需求审核、退回补充、排期、执行中、待领取及领取确认未形成完整办理链条。
- 差距：作废与实物是否已经耗用缺少明确区分，不能据此认定已实现全过程用纸核销。

## 4. 功能需求

- **PRT-01 需求登记与核对【已有基础，本期完善】**。适用角色：申请人、行政受理人。操作流程：登记或代录需求，填写用途、教师、班级、最终原稿、份数、页数、单双面、颜色及期望完成时间；对提取的候选信息逐项核对后提交。业务价值：减少口头遗漏和重复录入，确保执行要求明确。
- **PRT-02 受理、审批与退回【本期目标】**。适用角色：行政受理人、审批人。操作流程：检查需求完整性，按学校授权核准；需要补充时说明原因并退回，申请人补充后重新提交；批准后进入办理队列。业务价值：明确办理依据，避免未确认原稿或用纸要求直接进入生产。
- **PRT-03 计划用纸与排期【本期目标】**。适用角色：行政受理人、文印执行人。操作流程：依据份数、页数及印刷方式测算计划用纸，另列预计制版和试印用纸；确认办理顺序和预计完成时间，展示缺纸或延期事项。业务价值：提前安排工作量和耗材，计划量不被误当作实物消耗。
- **PRT-04 实际领纸与补领【本期目标】**。适用角色：文印执行人、物资经办人。操作流程：开印前核对纸张规格及实领数量，确认实物发出后扣减可用库存；不足时登记补领原因和数量，再确认补领。业务价值：清楚记录纸张从仓库交付文印人员的事实。
- **PRT-05 完工实耗核销【已有损耗登记基础，本期新增完整核销】**。适用角色：文印执行人、行政受理人。操作流程：登记合格印品数量、合格品耗纸、制版试印用纸、错印等损耗和未用余纸，核对实领数量的去向；有差异时补充说明并处理后确认完工。业务价值：区分计划与实际，准确分析损耗；完工核销不再次扣减已经领出的纸张。
- **PRT-06 余纸退回【本期目标】**。适用角色：文印执行人、物资经办人。操作流程：从原文印事项登记未用余纸，核对规格、数量及可用状态，验收接收后增加可用库存；损坏或已使用纸张按损耗处理。业务价值：让退库建立在真实可用实物上。
- **PRT-07 印品交接与领取【本期目标】**。适用角色：行政受理人、领取人。操作流程：完工后通知领取；领取人核对原稿版本和实际数量后确认，可分次领取并保留尚未领取数量；全部交付且用纸去向核对完成后归档。业务价值：把“印完”与“交付完成”分别跟踪。
- **PRT-08 变更、取消和重印【已有作废、重印识别基础，本期完善】**。适用角色：申请人、行政受理人、文印执行人、行政负责人。操作流程：变更时确认最新原稿和新增工作量；取消时核对执行程度、已耗用纸和剩余纸；重印明确原因并关联原事项，单独记录领纸及实耗。业务价值：保留更正依据，防止重复印刷和错误退库。
- **PRT-09 进度与用纸台账【已有基础，本期完善】**。适用角色：行政受理人、行政负责人。操作流程：按教师、班级、用途、期间查看办理状态，分别汇总计划、实领、实耗、损耗、退纸及待领取量。业务价值：解释用纸去向并识别积压；计划量、实领量和实耗量不得混为同一统计口径。

## 5. 流程与状态

现有主要状态为待印刷、已完成、已作废，不能据此推定存在审批和领取确认。

本期目标流程为：草稿 → 待受理或审批 → 待印刷 → 印刷中 → 待领取 → 已完成归档。退回补充后重新提交；未执行的需求可以取消；已经领纸或部分执行的需求，须完成耗用核对及余纸处置后标记为取消结案。

印品交付与用纸核对分别记录进度。印品全部领取但仍有余纸待退或数量差异的事项，继续列入待核销清单；用纸已核清但印品尚未领取的事项，继续列入待领取清单。异常事项应明确责任人、原因和下一步处理。

## 6. 业务规则

- 计划用纸只用于审批、排期和准备，不直接扣减可用库存，也不计入实际消耗。
- 实际领纸和补领在实物发出确认时扣库存；完工核销只确认领出纸张的去向，不重复扣库。
- 实际耗用包括合格印品耗纸、制版试印用纸及错印等损耗。实领纸张应能够解释为实际耗用、已退回的可用余纸及尚待处置余纸；存在无法解释的差异时不得直接核销完成。
- 只有未使用且验收可再用的余纸可以增加可用库存。已印纸张、试印纸和报废纸不能作为可用纸退库。
- 取消、作废或重印是业务处理决定，不自动证明发生了实物退回；已经耗用的数量必须保留在耗用记录中。
- 原稿和数量变更应由申请人确认；开印后发生的变更须说明已完成部分和新增部分，避免覆盖原有耗用事实。
- 聊天提取与文件识别结果仅为待核对信息，不能直接作为已审批、已开印或已领取的依据。
- 代领应记录实际领取人及所代领对象。分次领取不能超过合格印品可交付数量。
- 已确认的实物收发和耗用发生错误时，保留原记录和更正原因，经过核实后形成更正结果，不以删除记录掩盖差异。

## 7. 验收场景

以下数量均为验收示例，非学校真实数据。

- **PRT-A01 计划不扣库**：可用库存为1000张；申请100份、每份4页双面印刷，合格品预计用纸200张，另预计制版试印2张。提交并批准计划202张后，可用库存仍为1000张，实际耗用仍为零。
- **PRT-A02 领纸与完工不重复扣库**：上述事项实际领纸220张后，可用库存为780张。完工登记合格品耗纸200张、制版试印3张、错印损耗5张，实际耗用为208张，未用余纸12张；确认核销时不能再次扣208张。12张余纸验收退回后，可用库存为792张，实际耗用仍为208张。
- **PRT-A03 已耗用事项取消**：实际领纸80张，已经耗用60张，剩余20张未用。取消事项并验收退回20张后，只增加20张可用库存；60张耗用保留，不能把80张全部退库。
- **PRT-A04 退回补充及版本变更**：需求缺少最终原稿时，受理人说明原因退回；补充前不能进入待印刷。开印后更换原稿时，应能查看原版本已经印出的数量及耗用，并确认新版新增的办理要求。
- **PRT-A05 分次领取**：合格印品100份，第一次领取60份后仍显示40份待领取，不能标为全部交付；第二次领取40份后交付完成。若仍有余纸未核清，事项继续显示待核销。
- **PRT-A06 损耗与重印**：5张错印纸不能作为可用余纸退回；申请重印时保留原事项及损耗，重新确认重印数量和新增领纸，不能覆盖原有耗用记录。
