# 通知与台账

更新日期：2026-11-05。状态：P0 产品目标，当前仅完成静态梳理；本文件不表示功能已验收上线。

## 1. 用途与边界

内部通知用于告知制度、安排和注意事项；业务提醒用于推动具体申请或任务；台账用于查询真实发生的业务与处理记录。三者分别记录阅读、办理和收发结果。

本期覆盖现有主线事项的基础提醒、重要通知回执、统一查询和归档，不建设公文会签、综合效能评分或财务核算。

本文内部通知面向教职工。新增P0家校通知另见[学生与家长在校服务](07-学生与家长在校服务.md)：按适用学生形成发布范围快照，当前有效家长可见，每位家长分别记录阅读和主动确认，主统计为每学生至少一位当前有效监护人主动确认；已撤销关系旧回执留历史，不替代现关联确认，不得沿用内部通知“应读人员数”替代家校学生口径。开放日出入台账另见[家校开放日送物](08-家校开放日送物预约.md)，其“已入校未登记离校人数”不等于实时在校人数。

## 2. 参与角色

- 行政发布人员：确认通知内容、接收范围、有效时间及是否需阅读确认。
- 通知接收人：查看并按要求确认阅读；需要办事时进入关联事项处理。
- 经办人与负责人：接收本人负责事项的提醒，核查未结与超期事项。
- 台账查阅人员：在授权范围查看明细、汇总和处理依据。

## 3. 现有能力与差距

已有通知公告发布、部分阅读标记以及文印、物资、库存等独立报表。尚不能据此认定具备按人员范围完整送达、重要通知回执、自动跟随业务变化的提醒和一致的办结归档。

本期明确接收范围、提醒触发条件和统计口径，清除以示例或固定提示冒充正式业务结果的表达。报表须能够核查来源明细。

## 4. 功能需求

- **NTC-01 内部通知发布与撤回**  
  **适用角色：**行政发布人员、通知接收人。  
  **操作流程：**编辑草稿 → 指定接收范围、有效期和阅读要求 → 正式发布 → 必要时更正或撤回并说明原因。  
  **业务价值：**控制信息范围，减少过期和错误通知继续影响工作。

- **NTC-02 重要通知阅读确认**  
  **适用角色：**发布人员、接收人、相关负责人。  
  **操作流程：**接收人打开通知并确认阅读 → 发布人查询应读、已确认及未确认人员 → 对未确认人员提醒。  
  **业务价值：**核查重要安排是否被知悉，避免以“已发群”代替实际触达。

- **NTC-03 业务状态提醒**  
  **适用角色：**申请人、审核人、经办人、领取人。  
  **操作流程：**事项进入待处理环节 → 提醒对应人员 → 打开关联事项办理 → 完成后同步反映进度。  
  **业务价值：**减少漏审批、漏补充、漏领取及超期停滞。

- **RPT-01 统一台账与明细追溯**  
  **适用角色：**行政经办人员、文印与仓库人员、负责人。  
  **操作流程：**按时间、人员、部门、班级或物资筛选 → 查看来源单据、实际收发、退回、损耗及更正记录 → 核对汇总。  
  **业务价值：**让每个汇总数有业务依据，减少月底重复整理。

- **RPT-02 业务归档与授权导出**  
  **适用角色：**行政经办人员、授权查阅人员。  
  **操作流程：**确认事项已达到办结条件 → 汇集申请、意见、交付凭证和关联单据 → 归档查询或按权限导出。  
  **业务价值：**支持人员交接、争议核查和学校日常留档。

## 5. 流程与状态

- 通知：草稿 → 已发布 → 已关闭／已撤回；接收人另记录待阅读／已确认阅读。
- 业务提醒：对应事项进入待处理 → 提醒责任人 → 责任人办理 → 更新或结束该提醒；超期仍按原事项追踪。
- 台账：按实际业务发生形成记录 → 更正或实物退回时补充对应依据 → 达到条件后归档。

阅读通知不等于完成任务，接收提醒不等于领取实物，导出报表不等于相关事项已经办结。

## 6. 业务规则

- 内部通知与官网公开资讯分开。对外发布不能包含未经许可的试卷、内部审批意见和人员联系方式。
- 重要通知明确接收名单或范围；应读人数、已确认人数、未确认人数使用同一接收范围。
- 通知内容重大更正时注明更正，按需要重新要求确认；旧确认不能被解释为已经阅读新内容。
- 提醒始终关联同一事项。重复查看或重发提醒不会产生新的申请、领取确认或库存收发。
- 报表区分申请量、批准量、实际发放、实际消耗、完好退回、损坏处置及取消数量，不把申请总量视为实际消耗。
- 文印领纸与完工实耗不能重复计算出库；物资领退和对应出入库使用同一实际收发事实。
- 估算费用标明口径，实际采购金额有对应凭据；不能将按统一单价折算的费用当作已付款或精确采购成本。
- 作废、更正、归还和报损保留来源与原因；归档后通过关联更正记录反映变化，不抹去原责任记录。
- 查询、汇总和导出遵循相同业务权限。空结果、未取得结果和确实为零分别表达。

## 7. 验收场景

- **NTC-A01 定向发布**：仅选定部门接收内部通知，其他部门不在应读范围，汇总人数与名单一致。
- **NTC-A02 阅读与办理分离**：接收人确认阅读后，关联的待领物资任务仍未办结；实际确认领取后才结束领取待办。
- **NTC-A03 更正与撤回**：通知更正后保留原因，重要内容按要求重新确认；撤回通知不继续作为有效安排展示。
- **RPT-A01 汇总可核查**：筛选同一期间和同一部门，汇总能展开对应明细，明细合计与汇总一致。
- **RPT-A02 收发口径一致**：发放、退回、作废更正后，领退台账、出入库流水、库存余额和报表反映同一事实。
- **RPT-A03 不重复扣耗**：文印领纸后完工核销只确认实际耗用及退回，报表不把两次记录累计为双倍出库。
- **RPT-A04 归档完整**：办结事项可查询申请、审批、经办、交付与异常记录；未完成交付的事项不能仅因导出报表而办结。
- **RPT-A05 费用口径**：估算消耗费用和采购金额分别列示，无付款凭据时不显示“已付款”。
