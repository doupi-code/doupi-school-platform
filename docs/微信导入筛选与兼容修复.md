# 微信导入筛选与兼容修复

导入弹窗默认隐藏已确认的公众号、企业微信账号，每页显示 50 条，可切换 20/50/100 条。取消“隐藏公众号、企业号”即可恢复；“只看已勾选”只改变展示。被账号类型筛选隐藏的已勾选账号会保留选择，但不参与本次识别。

TraceMemo 的旧导出清单可能将所有会话写成 `user`。系统不会根据联系人名称猜测类型，而是读取导出目录内可选的 `联系人分类.json`，按会话 ID 匹配。缺少分类文件时，未知账号仍显示。

在 TraceMemo 连接数据库后，用 PowerShell 7 执行以下命令补齐新导出目录的分类：

```powershell
./scripts/export-wechat-account-types.ps1 -ExportDirectory 'C:/Users/javal/Desktop/weixin/全部聊天记录'
```

脚本从本机环境变量 `TRACEMEMO_API_TOKEN` 读取凭证（兼容旧变量），先检查公开 health 接口，再读取联系人类型。仅写入会话 ID 与账号类型，不修改聊天内容，不把凭证保存到文件。生成后须在浏览器重新选择导出文件夹。

`crypto.randomUUID` 不可用时，界面批次与任务标识回退到 `getRandomValues`；无 crypto API 时使用时间、递增序列及随机数。这些标识只用于本地界面隔离，不用于鉴权或持久化消息去重。

数据库防重补丁部署前，还需执行 `doupi-server/sql/upgrade_print_source_registration_lock.sql`。来源锁在事务提交/回滚时释放；不要在导入期间清理锁表。原有额外用纸和消息来源字段升级脚本仍须执行。

验证分为：前端单测、模拟接口的真实 Edge 浏览器交互测试，以及 H2 + Spring 事务 + 生产 MyBatis 来源锁 SQL 的后端测试。后两者不等同于生产 MySQL 全链路验证。
