# 微信预填重构执行记录
依据：本聊天中用户批准的完整实施计划。
- 当前分支 codex/wechat-prefill，独立工作区；不推送、不部署。
- 任务1：消息规范化和需求解析，回归测试。
- 任务2：剪贴板、附件匹配、可空字段契约。
- 任务3：逐条登记、原文对照、草稿隔离和保存保护。
- 任务4：验证、审查、文档和用户要求的记忆说明。
- 决策：保留现有单条登记事务，历史记录仅作为疑似重复提示，不自动跳过。

## 结果
- 已实现消息实例解析、可空字段和原话证据；用户追加要求落实为默认显示当天全部聊天。
- 已统一文本/HTML/文件粘贴，上传失败保留，重复文件名要求手动关联。
- 已拆分候选列表和原文面板；逐条表单草稿保留，保存失败不推进。
- 审查修复：预览索引与表单索引分离；图片/文件异步回调隔离；导入保存互斥；前置指令、多条说明、纯时间和独立页数回归。
- 旧测试中的猜测默认值及自动跳过断言按新契约更新。导出测试的个人绝对路径改为JUnit临时目录，以便全模块测试跨工作区运行。
- 本地验证：后端31项测试；前端5项单测、浏览器集成验证、TypeScript检查及Vite构建通过。浏览器API全为模拟，没有写入业务数据。
- 未推送、合并或部署。真实微信复制路径尚须用户本机验收。
